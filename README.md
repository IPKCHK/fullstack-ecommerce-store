# Full-Stack PERN E-Commerce Application

A modern, fully responsive e-commerce web application built using the PERN stack (PostgreSQL, Express.js, React, Node.js).

## Tech Stack
* **Frontend:** React, Vite, Tailwind CSS / Custom CSS
* **Backend:** Node.js, Express.js, JSON Web Tokens (JWT), Bcrypt
* **Database:** PostgreSQL (Hosted on Neon)
* **Deployment:** Render (Backend API) & Vercel (Frontend UI)

## Features
* User authentication and secure password hashing.
* Product catalog with dynamic cart management and order summary calculations.
* RESTful API architecture with CORS security and route protection.
* Fully containerized and deployed in production.
